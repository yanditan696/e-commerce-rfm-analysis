# E-commerce Online Retail Analysis
Dataset: UK Online Retail Dataset (540K+ order records)
Tools: Python, Pandas, Matplotlib

## Project Overview
This project analyzes e-commerce order data to explore sales patterns and segment users with RFM model.

## Workflow
1. Data cleaning: Remove return orders and abnormal records with negative price.
2. Descriptive analysis: Monthly sales trend, sales distribution by country, top-selling products.
3. RFM User Segmentation: Segment users by Recency, Frequency, Monetary value.
4. Business suggestion: Differentiated marketing strategies for each user group.

## Key Findings
- Sales peak in November, driven by holiday season.
- UK contributes the vast majority of revenue.
- Most users are general-value users; dormant high-value users are the priority for recall campaigns.
